# Nova Voice Assistant
Tamil + English bilingual Flask voice assistant using Google Gemini.

## Run
1. `python -m venv venv`
2. Windows: `venv\\Scripts\\activate`
3. `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` and add API keys.
5. `python app.py`
6. Open `http://127.0.0.1:5000`

Features: Tamil/English recognition, speech output, Hey Nova wake word, continuous voice mode, local chat history, weather, and Google web search. Use Chrome or Edge and allow microphone access.
